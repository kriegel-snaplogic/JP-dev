# Image Embedding Reference

Quick reference for embedding images in LaTeX documents.

## Syntax

```
[IMAGE:path:caption:width]
```

### Parameters

1. **path** (required): Path to image file
   - Can be absolute: `/tmp/diagram.png`
   - Can be relative: `images/chart.png`
   - Looks in skill directory, assets, and current working directory
   
2. **caption** (optional): Text caption below image
   - Use descriptive text: `System Architecture Diagram`
   - Use `_` for no caption: `_`
   - Omit entirely for default (no caption): `[IMAGE:path.png]`

3. **width** (optional): Image width as decimal of text width
   - Default: `0.8` (80% of text width)
   - Recommended range: `0.3` to `0.9`
   - Examples: `0.5` (50%), `0.7` (70%), `0.9` (90%)

## Examples

### Basic image with caption
```
[IMAGE:diagram.png:System Architecture:0.7]
```
Result: Image at 70% width with caption "System Architecture"

### Image without caption
```
[IMAGE:chart.png:_:0.5]
```
Result: Image at 50% width, no caption

### Image at default width
```
[IMAGE:photo.jpg:Team Photo]
```
Result: Image at 80% width with caption "Team Photo"

### Multiple images in one section
```
First, the overview:

[IMAGE:overview.png:Overview Diagram:0.6]

Then the details:

[IMAGE:details.png:Detailed View:0.6]

Both images will appear in order with their respective captions.
```

## Supported Formats

✅ **Recommended:**
- PNG - Best for logos, diagrams, screenshots (lossless)
- JPG - Good for photos (compressed)
- PDF - Vector graphics (if generated by LaTeX-compatible tools)

❌ **Avoid:**
- SVG - LaTeX has poor SVG support, convert to PNG first
- GIF - Not well supported, use PNG instead
- TIFF - Rarely supported, convert to PNG or JPG

## Best Practices

### File Paths
- Use absolute paths for reliability: `/tmp/images/diagram.png`
- Or place images in skill directory: `assets/images/chart.png`
- Verify file exists before referencing

### Image Sizing
- **0.3-0.4**: Small supporting images, inline graphics
- **0.5-0.6**: Medium diagrams, charts
- **0.7-0.8**: Large primary images (default)
- **0.9**: Full-width hero images

### Captions
- Be descriptive: "System Architecture with Microservices"
- Not just file names: Avoid "diagram.png"
- Use `_` when image is self-explanatory

### Image Quality
- Use high resolution (300+ DPI for print)
- Ensure readable text in diagrams
- Compress large images before embedding

## Common Issues

### "Image not found"
- Check file path is correct
- Verify file exists: `ls /path/to/image.png`
- Ensure file permissions are readable

### "LaTeX compilation failed"
- SVG files not supported - convert to PNG
- Very large images cause memory issues - resize first
- Corrupted image files - verify file opens normally

### Images don't appear
- Check syntax: `[IMAGE:path:caption:width]`
- Verify colons separate parameters
- Ensure path has no spaces (or escape them)

### Images appear too small/large
- Adjust width parameter (0.3 to 0.9)
- Default is 0.8 if not specified
- Test different values to find optimal size

## Converting SVG to PNG

If you have SVG files, convert them first:

```bash
# Using ImageMagick
convert input.svg -density 300 output.png

# Using Inkscape
inkscape input.svg --export-png=output.png --export-dpi=300

# Online tools
# upload to convertio.co or similar
```

## Error Handling

If an image is not found, the document will show:
```
[Image not found: path/to/file.png]
```
(displayed in red text)

This allows compilation to continue while highlighting missing images.

## Integration with Document Types

Image embedding works with all document types:

- **Technical documents**: Diagrams, flowcharts, API schemas
- **General/Customer-facing**: Architecture, screenshots, branding
- **Internal documents**: Charts, graphs, process diagrams

The syntax is identical across all document types.

## List of Figures

Documents with images automatically include a **List of Figures** after the Table of Contents. The List of Figures shows:

- Figure number
- Caption text
- Page number

**Example List of Figures:**
```
List of Figures
1   System Architecture Diagram . . . . . . . . . . . . . . . . . 3
2   API Request Flow . . . . . . . . . . . . . . . . . . . . . . . 5
3   Performance Metrics Chart . . . . . . . . . . . . . . . . . .  7
```

**Notes:**
- Only figures **with captions** appear in the List of Figures
- Figures without captions (using `_`) are excluded from the list
- The List of Figures is automatically generated - no configuration needed
- If no figures have captions, the List of Figures is omitted entirely
