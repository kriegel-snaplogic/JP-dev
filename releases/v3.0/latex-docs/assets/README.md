# Assets Directory

This directory contains branding assets for SnapLogic documents.

## Structure

### logos/
Place company logo files here:
- `snaplogic_logo.png` or `snaplogic_logo.pdf` - Primary SnapLogic logo
- `snaplogic_logo_white.png` - White version for dark backgrounds (if needed)
- Customer logos can be added dynamically or stored here with descriptive names

Supported formats: PNG, PDF, SVG (PDF preferred for LaTeX)

### fonts/
Place custom fonts here if needed:
- TTF or OTF font files
- Font license information

If using standard fonts (Computer Modern, Times, Helvetica), no files needed here.
