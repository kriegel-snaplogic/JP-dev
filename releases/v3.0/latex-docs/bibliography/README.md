# Central Bibliography Database

This directory contains the central BibTeX database for technical citations.

## files.bib
Main bibliography file containing all technical references.

Each entry should include:
- Unique citation key
- Date added or last validated
- Standard BibTeX fields (author, title, year, etc.)

The skill will:
1. Search this database first for citations
2. Revalidate references older than 30 days
3. Add new references as needed
